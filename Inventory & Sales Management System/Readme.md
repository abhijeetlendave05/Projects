# Inventory & Sales Management System

A Python-based desktop application for managing products, inventory, and sales transactions.

## Features

- Add products
- Update products
- Delete products
- Product search
- Inventory tracking
- Stock management
- Low-stock monitoring
- Sales management
- Automatic stock update after sales
- Dashboard
- SQLite database
- CRUD operations
- Automatic data refresh

## Technologies Used

- Python
- Tkinter
- SQLite
- SQL
- Object-Oriented Programming

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python main.py
